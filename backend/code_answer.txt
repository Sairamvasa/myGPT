Here is the complete Java program that calculates the Greatest Common Divisor (GCD) of 48 and 18 using the Euclidean algorithm.

```java
public class GCDCalculator {

    /**
     * Calculates the Greatest Common Divisor (GCD) of two numbers
     * using the Euclidean algorithm.
     *
     * @param a First integer
     * @param b Second integer
     * @return The greatest common divisor of a and b
     */
    public static int findGCD(int a, int b) {
        // Handle negative numbers by converting them to positive
        a = Math.abs(a);
        b = Math.abs(b);

        // Euclidean algorithm
        while (b != 0) {
            int temp = b;
            b = a % b;
            a = temp;
        }
        return a;
    }

    public static void main(String[] args) {
        int num1 = 48;
        int num2 = 18;

        int gcd = findGCD(num1, num2);

        System.out.println("The GCD of " + num1 + " and " + num2 + " is: " + gcd);
    }
}
```

### Explanation

1. **Euclidean Algorithm**: The program uses the standard Euclidean algorithm, which efficiently computes the GCD of two numbers by repeatedly taking the remainder of their division (`a % b`) until the remainder becomes `0`.
   - Step 1: $48 \pmod{18} = 12$
   - Step 2: $18 \pmod{12} = 6$
   - Step 3: $12 \pmod{6} = 0$
   - Result: **6**
2. **Edge Case Handling**: `Math.abs()` ensures the method works correctly even if negative integers are passed as arguments.
