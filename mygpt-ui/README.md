# MyGPT UI

This directory contains the Next.js client for MyGPT. Project-wide setup and
backend instructions are in the repository root [README.md](../README.md).

## Commands

```powershell
npm install
npm run dev
npm run lint
npm run build
```

Set `NEXT_PUBLIC_API_URL` to the running FastAPI backend URL when developing
locally or deploying the client.
